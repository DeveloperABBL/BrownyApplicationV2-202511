เก็บคูปอง Shop แล้วเด้งไปแท็บซัก-อบ

⏸️ รอ backend (revert แล้ว)
ต้นเหตุ
onCouponCollected hardcode _tabController.animateTo(0) เด้งไปแท็บ 0 (ซัก-อบ) เสมอ หลังเก็บคูปองทุกประเภท
ทำไมพัก
การจะอยู่/ไปแท็บที่ถูก ต้องรู้ "ประเภทคูปอง" ที่เพิ่งเก็บ — แต่ response ของ collect ปัจจุบันไม่มี flag ระบุประเภท เลยเดาไม่ได้
ต้องการ
backend เพิ่ม flag ประเภทคูปอง (ซัก-อบ / e-voucher / browny-shop) ใน response ของ collect → client ค่อยเลือกแท็บ + refetch list ให้ถูก

กดชำระด้วย Browny Coin ไม่ได้

⏸️ รอ backend / QA
ผลตรวจ
โค้ด client มี branch coin ครบ ไม่มีจุด block/disable และ coin ไม่ถูก filter ออกจากรายการวิธีชำระ
น่าจะเป็น
backend (confirm coin ไม่คืน status: paid / ไม่รองรับ coin) หรือยอด coin ไม่พอ (เด้ง dialog "coin ไม่พอ")
ต้องการ
อาการจริงจาก QA (ปุ่มไม่ติด? error? dialog?) + backend ยืนยันรองรับ coin · client เสริม: reset flag กันคลิก + จัดการกรณี coin คืน non-paid

ชำระแล้ว แต่สินค้ายังอยู่ในตะกร้า

⏸️ รอ backend
ต้นเหตุ
API จริง server ควรล้างตะกร้าตอนชำระสำเร็จ — ถ้ายังอยู่ = backend ไม่ล้าง/ล้างผิดจังหวะ · client เองก็ไม่มี clearCart กันเหนียว
ต้องการ
backend ยืนยันจังหวะล้างตะกร้า · client เสริม clearCart/refresh หลัง paid

รายการที่ยังไม่ชำระไม่ขึ้นในตะกร้า

⏸️ รอ backend / UX
ต้นเหตุ
flow "confirm สร้าง order ก่อนจ่าย" → cart ถูก consume ตั้งแต่ confirm → ของออกจากตะกร้าไปเป็น pending order
ต้องการ
ตัดสินใจ UX: (ก) backend ไม่ consume cart จนกว่าจะจ่าย หรือ (ข) แสดง pending order ให้ชัด + resume ได้

ออกจากการชำระ → กลายเป็นค้างชำระ ไม่ค้างในตะกร้า

⏸️ รอ backend / UX
ต้นเหตุ
ต้นเหตุเดียวกับข้อ 9 · pending order โผล่ที่ Home/ประวัติ/หน้าสถานะ (ปุ่ม "ชำระเงิน") แต่ไม่ใช่ในตะกร้า
ข้อสังเกต
endpoint GET /browny-shop/pending-payment มีอยู่แต่ยังไม่ถูกเรียกเลย — เอามา wire แสดงแบนเนอร์ "ชำระต่อ" ได้

ยกเลิกสินค้าค้างชำระไม่ได้

🚫 Blocked
ต้นเหตุ
ไม่มีทั้ง API / repo / UI สำหรับยกเลิก pending order เลย
ต้องการ
backend เพิ่ม endpoint ยกเลิก ก่อน แล้วจึงต่อ repo → ViewModel → ปุ่ม "ยกเลิกคำสั่งซื้อ" ในหน้าสถานะ (แสดงเมื่อ pending_payment)

❓ คำถามที่ต้องเคลียร์กับ Backend

  1. QR checkout: cart ถูก consume ตอน confirm หรือตอน paid? (ตัดสินชะตาข้อ 8 / 9 / 10)
  2. Browny Coin: confirm ด้วย coin คืน status อะไร และรองรับ coin สำหรับ Browny Shop ไหม? (ข้อ 7)
  3. Coupon type flag: เพิ่ม field ระบุประเภทคูปองใน response ของ collect ได้ไหม? (ข้อ 6)
  4. Cancel order: มี/จะเพิ่ม endpoint ยกเลิก pending order ไหม + ยกเลิกแล้วของกลับเข้า cart หรือหาย? (ข้อ 11)
